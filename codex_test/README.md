# codex_test

元のカンプHTMLを変更せず、第1〜第3の作業紹介セクションだけを調整する比較用コピーです。

## 開き方

`index.html` をブラウザで開いてください。画像8点と調整用JavaScriptは同じフォルダ内にあります。

## 調整内容

- 第1〜第3を290px間隔の共通リズムに統一
- 写真と文章ブロックの縦中心を統一
- 番号と見出しの間隔を統一
- 番号画像を78px角にして正円を維持
- 写真の影と白枠を弱める
- セクションの上方向への重なりを緩和

調整値は `layout-fix.js` にまとめています。元HTMLは `data/camps` 側に残っています。
